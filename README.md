GARAGE 24 — демонстрационный адаптивный лендинг автосервиса.

Как открыть: распакуйте архив и откройте index.html в браузере.
Перед передачей реальному клиенту замените название, телефон, адрес, цены и тексты.
Форма сейчас демонстрационная: для реальной отправки заявок нужен backend или сервис форм.
